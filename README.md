# Суфлёр

Бесплатный суфлёр для записи видео на айфоне: фронтальная камера на весь экран, запись видео
со звуком, окошко с текстом можно таскать и менять размер. Тап — старт/пауза, двойной тап — в начало.

Открыть: https://valikw.github.io/suflyor/ — в Safari «Поделиться → На экран „Домой“».

- `index.html`, `manifest.json`, `icon.png` — всё приложение.
- `ios/` — нативный прототип на Swift. Не используется: с бесплатным Apple ID работает 7 дней.

Проверка на компе: `python3 -m http.server 8765` в этой папке. Выкладка — `git push` (GitHub Pages).
